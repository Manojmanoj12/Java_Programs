# 📘 Java Programs Repository

Welcome to the **Java Programs** repository!  
This collection contains simple to intermediate-level Java programs written to strengthen understanding of Java fundamentals, object-oriented programming, and problem-solving techniques.

---

## 🚀 Technologies Used

- **Language:** Java (JDK 8+)
- **Concepts Covered:**
  - Basic Syntax and Structure
  - Variables, Operators, and Data Types
  - Control Flow (if, else, switch)
  - Loops (for, while, do-while)
  - Functions and Recursion
  - Arrays and Strings
  - Object-Oriented Programming (OOP)
  - Exception Handling
- **IDE Suggestions:** IntelliJ IDEA / Eclipse / NetBeans / VS Code

## 🧑‍💻 Sample Programs

- **`ArmstrongNumber.java`** – Checks if a number is an Armstrong number.
- **`Factorial.java`** – Calculates factorial using loop or recursion.
- **`Palindrome.java`** – Validates if a string or number is a palindrome.
- **`FibonacciSeries.java`** – Generates Fibonacci sequence up to n terms.
- **`GCD.java`** – Computes the Greatest Common Divisor.
- **`Calculator.java`** – Basic calculator operations using switch case.
- **`PrimeCheck.java`** – Determines whether a number is prime.

## 🛠️ How to Run

### Prerequisites

- Java JDK installed and environment variables set.

### Steps

1. **Clone the Repository**

```bash
git clone https://github.com/Manojmanoj12/Java_Programs.git
````

2. **Navigate to the Folder**

```bash
cd Java_Programs
```

3. **Compile and Run a Program**

```bash
javac FileName.java
java FileName
```

> Replace `FileName.java` with the program you wish to run.
